# Roadmap

## Блок 1 — Architecture Freeze + Headless World Kernel — COMPLETE

Утверждённые документы, детерминированный мир, событийный планировщик, scripted policy, базовые действия, event hash chain, snapshot save/load, headless CLI и минимальный FastAPI-каркас.

## Блок 2 — Executive Layer + LLM Agents + Memory — COMPLETE

Provider interfaces, Ollama, partial prompt context, строгие intents, repair/fallback, model hot-swap,
four-layer SQLite memory, compaction/forgetting, subjective beliefs, async messages/offers,
минимальный commitment lifecycle и семантическая проверка snapshot реализованы и приняты полным
локальным checkpoint-набором.

## Блок 3 — Visual Observer MVP — COMPLETE

Три визуальных направления Product Design и выбор одного. Затем Phaser-карта, панели, inspector, day/night/weather, WebSocket, reconnect, pause/speed и browser QA.

## Блок 4 — Experimental MVP — COMPLETE

Три агента, остров, семь дней; offer/response, transfer, promises, совместный проект, кризис, метрики, export и exact Decision Replay без сети.

## Блок 5 — Research Layer + Local Checkpoint — COMPLETE

Каталог запусков, проверяемый reproducibility manifest, rerun, mandatory minimal replication,
ветка только из time-zero snapshot, comparison/first semantic divergence, JSON/Markdown/SVG
отчёты, journal вмешательств, read-only research API и проверенный локальный Windows launcher.
Формальный security scan и public-release audit по явному решению оператора отложены до подготовки
публичного выпуска; этот checkpoint не заявляет security certification.

## Horizon A — Social and Information Expansion

Собственность, делегирование, коалиции, репутация и слухи, полноценные договоры, журналы, летописцы, региональные доски событий, библиотеки и физическое распространение информации.

## Horizon B — Historical Continuity

Смерть, ученики, поколения, архивы, биографии объектов, руины, исчезнувшие поселения и археология.

## Horizon C — Emergent Institutions

Самоопределяемые профессии, рынки, суды, академии, государства, культура, традиции и технологии — только как обнаруженные паттерны, не scripted behavior.

## Horizon D — Research Platform

History tree, массовая replication, hypotheses, causal graph, discovery/pattern detectors, batch experiments и статистическое сравнение.

## Horizon E — Experimental Frontier

Dynamic Mind, World Consciousness, большие популяции, распределённое выполнение, моддинг и пользовательские миры.
